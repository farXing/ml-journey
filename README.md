\## Цель проекта

Изучение основ машинного обучения, ведение первого проекта в git, а также его правильное оформление. Создание собственной нейронной сети без использования готовых библиотек для реализации градиентного спуска. Самостоятельное создание датасета для обучения нейросети с репликами персонажа. Как итог, реализация чата с персонажем, который сможет достаточно долго вести себя в характере и не терять контекст разговора.
